# Blood Donation Management App 🩸

A comprehensive mobile application designed to bridge the gap between blood donors and those in urgent need. Users can register as donors, track their donation history, find nearby donors, and post real-time blood requests.

## ✨ Features

* **User Authentication:** Secure email/password login, Google Sign-In, and OTP-based password recovery.
* **Donor Directory:** Filter donors by blood type and location (Division, District, Area).
* **Smart Donation Countdown:** Automatically calculates eligibility for the next donation date.
* **Emergency Blood Requests:** Post urgent requests with details (hospital name, deadline, location).
* **Save/Pin Requests:** Bookmark specific blood requests and mark them as completed once fulfilled.
* **Donor Profile Management:** View, update, or permanently delete donor account data.
